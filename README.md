# 📊 E-commerce Sales Dashboard | Tableau

## Project Overview

This project presents an interactive Tableau dashboard built using an E-commerce dataset. The dashboard helps analyze sales performance, profitability, customer behavior, product categories, regional performance, discounts, and returned orders.

## Objectives

* Analyze overall sales and profit performance.
* Identify top-performing categories and regions.
* Understand the impact of discounts on profit.
* Track returned orders.
* Provide interactive filters for dynamic analysis.

## Dashboard Features

* Sales Analysis
* Profit Analysis
* Category-wise Performance
* Region-wise Performance
* Discount vs Profit Analysis
* Returned Orders Analysis
* Interactive Filters (Region, Category, Segment, Order Date)

## Tools Used

* Tableau
* Microsoft Excel

## Key Insights

* Identified high-performing regions and categories.
* Analyzed the relationship between discount and profit.
* Monitored returned orders and their impact on business performance.
* Built an interactive dashboard for better decision-making.
